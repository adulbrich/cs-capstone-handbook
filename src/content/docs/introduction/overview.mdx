Senior Software Engineering Project I, II, and III, together called **Capstone**, are the three-term senior project sequence in the Computer Science major.

Term   | ID       | Class Name | Credits
-------| ---------|------------|--------
Fall   | CS 461   | Senior Software Engineering Project I   | 3
Winter | CS 462   | Senior Software Engineering Project II  | 3
Spring | CS 463   | Senior Software Engineering Project III | 2

Students work in [teams](/practicalities/projects-and-teams/) of 3 to 4 on one project for a real project partner, from a problem statement in fall to a released artifact with real users in spring.

## How We Measure Success

Each term, the grade combines four equal components: your project partner's evaluation, your teammates' peer evaluations, individual evidence that nobody can produce for you, and the team's deliverables. The emphasis shifts across the three terms to follow how a real project progresses.
